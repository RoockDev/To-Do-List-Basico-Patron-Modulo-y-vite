# 📝 To-Do List (Patrón Módulo + Vite)

Este es un **ejercicio básico de lista de tareas** (to-do list) desarrollado como parte del aprendizaje del **patrón módulo** en JavaScript, usando **Vite** como entorno de desarrollo.

## 🎯 Objetivo

Crear una aplicación muy sencilla que permita:
- Añadir una nueva tarea.
- Mostrar todas las tareas.
- Marcar una tarea como completada.
- Eliminar una tarea.

Todo ello organizado con el **patrón módulo**, separando la lógica de negocio (gestión de tareas) de la interacción con el DOM.

## 🛠️ Tecnologías
- JavaScript moderno (ES6+)
- Patrón módulo (con `export`/`import`)
- Vite (plantilla vanilla)
- HTML5 + CSS básico
